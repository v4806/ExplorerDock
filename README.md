# ExplorerDock

把 Windows 任务栏上的窗口按钮，搬进一条置顶显示的悬浮栏。

开着多个窗口干活时，任务栏会被一排窗口按钮塞满。
ExplorerDock 把这些按钮从任务栏拿走，
收进一条轻量悬浮栏，点一下就切过去。

## 功能

- 窗口的按钮从任务栏移除，改由悬浮栏集中显示与切换；新开的自动出现，关掉的自动消失
- 左键切换、已经在最前则最小化；当前活动的窗口按钮会高亮
- 按钮显示窗口名与所在路径，图标取自实际路径
- 深色 / 浅色 / 跟随系统 / 完全自定义（配色、边框线宽、整体缩放、字体）
- 接管 ALT+TAB：使用更加强大的应用切换卡片
- 悬浮栏位置可拖动并记住
- 悬浮栏贴边自动隐藏、居中模式、锁定位置
- 悬浮栏可切换横幅/堆叠模式
- ALT+TAB切换应用卡片列表可合并同名程序窗口

## 安装

到 [Releases](../../releases) 下载 `ExplorerDock-Setup-x.y.z.exe` 双击安装（自带 .NET 运行时，无需额外环境）。
也可以下 `ExplorerDock-x.y.z-portable.zip` 免安装运行，但那需要系统已装 .NET 10 Desktop Runtime。

## 首次启动

第一次运行会弹出**设置向导**，逐步确认接管范围、悬浮栏行为、配色和启动方式 —— 每一步都立即生效，能当场看到变化。
其中「以管理员身份运行」默认勾选，取消时会提示后果。向导跑完之后，随时可以从菜单里的「设置向导…」再走一遍。

## 用法

| 操作 | 行为 |
| --- | --- |
| 左键点按钮 | 切到该窗口；已在最前则最小化 |
| 中键点按钮 | 关闭该窗口 |
| 右键点按钮 | 切换 / 最小化 / 复制路径 / 关闭窗口 等 |
| 按住悬浮栏任意位置拖动 | 移动位置（会被记住） |
| 滚轮 | 窗口太多时横向或竖向滚动 |

托盘图标：双击显示 / 隐藏悬浮栏，右键是全部设置。

## ALT+TAB

Windows 把「任务栏上的按钮」和「ALT+TAB 里的条目」当成同一份窗口清单来管，没法只拿掉其中一个：
文件夹按钮被收进悬浮栏之后，这些窗口在系统 ALT+TAB 里也跟着消失了。

所以 ExplorerDock 自己接管了 ALT+TAB —— 弹出的切换面板是本程序画的，窗口清单也是自己数的，
那些被摘掉任务栏按钮的文件夹窗口照样在里面。

| 操作 | 行为 |
| --- | --- |
| `Alt`+`Tab` | 弹出切换面板，往后选 |
| `Shift`+`Alt`+`Tab` | 往前选 |
| `Alt`+`~` | 在合并的同名进程窗口之间切换 |
| 松开 `Alt` | 切到选中的窗口 |
| `Esc` | 取消，留在原来的窗口 |
| 鼠标点卡片 | 直接切过去 |

设置菜单里的「接管 Alt+Tab 切换」可以随时关掉，关掉后立刻交还系统。

几件需要知道的事：

- **用管理员身份运行的程序，需要本程序也有管理员身份才管得到**：否则这类程序占着前台时，Alt+Tab 会交给系统处理（不会出现「按了没反应」）。
  把菜单里的**「以管理员身份运行」**勾上即可（向导里默认就是勾的）；勾选或取消都会自动按新状态重启一次，之后每次启动都记着这个选择。
  代价是每次开机会多一次系统权限提示。
- **全屏游戏里默认交给系统处理**：那种画面会挡住本程序的切换界面，硬接管会变成「按了没反应、切不出去」。想让本程序也管全屏游戏，把菜单里的这一项关掉即可。
- 和 AutoHotkey 之类的 ALT+TAB 替换工具同时开着会互相抢输入，二选一。
