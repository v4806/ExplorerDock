# ExplorerDock

把 Windows 任务栏上的文件夹窗口按钮，搬进一条置顶显示的悬浮栏。

开着十个文件夹干活时，任务栏会被一排长得一样的文件夹按钮塞满。
ExplorerDock 把这些按钮从任务栏拿走，
收进一条轻量悬浮栏，点一下就切过去。

## 功能

- 文件夹窗口的按钮从任务栏移除，改由悬浮栏集中显示与切换；新开的自动出现，关掉的自动消失
- 左键切换、已经在最前则最小化；当前活动的文件夹会高亮
- 按钮显示文件夹名与所在路径，图标取自实际路径
- 深色 / 浅色 / 跟随系统 / 完全自定义（配色、边框线宽、整体缩放、字体）
- 悬浮栏位置可拖动并记住

## 安装

到 [Releases](../../releases) 下载 `ExplorerDock-Setup-x.y.z.exe` 双击安装（自带 .NET 运行时，无需额外环境）。
也可以下 `ExplorerDock-x.y.z-portable.zip` 免安装运行，但那需要系统已装 .NET 10 Desktop Runtime。

## 用法

| 操作 | 行为 |
| --- | --- |
| 左键点按钮 | 切到该文件夹；已在最前则最小化 |
| 中键点按钮 | 关闭该文件夹窗口 |
| 右键点按钮 | 切换 / 最小化 / 复制路径 / 关闭窗口 等 |
| 按住悬浮栏任意位置拖动 | 移动位置（会被记住） |
| 双击 `⠿` 把手 | 隐藏悬浮栏 |
| 右键 `⠿` 把手 | 设置菜单 |
| 滚轮 | 文件夹太多时横向滚动 |

托盘图标：双击显示 / 隐藏悬浮栏，右键是全部设置。

## 已知取舍

Windows 把「任务栏上的按钮」和「ALT+TAB 里的条目」当成同一份窗口清单来管，没法只拿掉其中一个。
所以把文件夹按钮从任务栏收走之后，这些窗口在 ALT+TAB 里也就不出现了。

窗口本身没受任何影响，照常在桌面上开着 —— 用悬浮栏点一下就切过去，这也正是这个软件存在的意义。
