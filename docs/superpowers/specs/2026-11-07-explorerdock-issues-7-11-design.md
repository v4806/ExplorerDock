# ExplorerDock #7-#11 修复设计

## 目标

依据 GitHub 开放 issue #7-#11 校正当前 `fix/issues-2026-10` 分支的实现，保留已经完成的功能，只修复与这五条反馈直接相关或会造成明显回归的边界问题。完成后执行可重复验证、同步仓库、逐条回复并关闭 issue。

## 非目标

- 不重做剪贴板面板、Alt+Tab 面板或菜单结构。
- 不新增自定义剪贴板热键。
- 不处理与 issue 无关的 DPI manifest 警告。
- 不为本次任务引入大型 UI 测试框架。
- 不发布新 Release，也不创建没有安装包的版本标签。

## 结论

| Issue | 处理 |
| --- | --- |
| #7 剪贴板搜索 | 保留现有搜索和收藏分组叠加逻辑；搜索框获得焦点时，Delete 始终交给文本框，不删除历史。 |
| #8 Alt+Tab 鼠标悬停 | 现有默认关闭、点击仍有效，无需改代码，只做验收。 |
| #9 多虚拟桌面 | 保留悬浮栏轮询过滤；Alt+Tab/Alt+~ 打开时在当前 STA 上重新查询当前桌面，避免使用上轮白名单；连接建立后强制补发一次完整快照。 |
| #10 中文输入误弹剪贴板 | 热键只能从本钩子实际观察到的 Win 按下开始；左右 Win 分开跟踪；物理状态只用于否决陈旧状态。禁用接管时不再开始新序列，但必须收完已经吞下的按键释放。宿主剪贴板热键镜像默认关闭，由界面在控制器真正就绪后开启。 |
| #11 剪贴板总开关 / Explorer 排除 | 先通知宿主停止 Win+V 接管，再拆监听和库；监听注册失败必须抛出并走现有回滚。Explorer 窗口类优先服从独立开关，不能被上一轮接管句柄集合覆盖。 |

## 验证原则

- 纯状态机与优先级用无外部测试包的 `ExplorerDock.IssueTests` 控制台断言验证。
- 所有行为修项先写失败测试，再写最小实现。
- WPF 搜索、真实中文输入法、Alt+Tab、Win+V、虚拟桌面、任务栏归还必须在本机交互桌面完成。
- 真实交互测试使用临时设置与剪贴板数据；原用户数据先备份，测试后恢复。
- 最终以 `git diff --check`、Release/x64 构建、IssueTests 和人工验收记录为证据。

## 验收结果

- #7：搜索正文、文件路径和类型关键词有效；中文输入不误触；空搜索框 Delete 不删记录。
- #8：默认悬停不改变键盘选中；点击仍切换；显式开启后移动鼠标才改变选中并持久化。
- #9：A/B 桌面同数量窗口往返后，悬浮栏和立即打开的 Alt+Tab 都只显示当前桌面窗口。
- #10：普通 V、中文组字、组合键、长按和接管启停均不误弹或吞键；真实左右 Win+V 各触发一次。
- #11：关闭总开关后不采集、不接管 Win+V，重启仍关闭；重开保留历史并恢复采集；取消 Explorer 接管后任务栏、悬浮栏和分组判定同步恢复。
